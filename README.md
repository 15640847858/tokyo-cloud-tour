# 云游东京 · Tokyo Cloud Tour

一张可以走进的 3D 东京地图：为没来过日本的朋友做的沉浸式导览。真实 OpenStreetMap
地图与建筑轮廓之上，立着 26 处手工建模的景点与机场——晴空塔、东京塔、浅草寺、
涩谷十字路口、东京巨蛋、国立竞技场、富士山与镰仓高校前……点开任意景点，有实景
照片、历史与攻略、最近车站与路线，还有可以盖章收集的御朱印护照。

在线访问：https://ibun.fun

## 特色

- **真实城市肌理**：市中心约 14,000 栋建筑按 OSM 真实轮廓生成，住宅带坡屋顶、
  立面带阳台/空调/店铺招牌与自动贩卖机；地标建筑逐个手工建模，非方块拼凑
- **与东京同步**：实时天气（晴/阴/雨/雷雨/雪都会落在地图上）、按真实日出日落
  切换清晨/白天/黄昏/夜晚、东京时钟
- **五种语言**：中文 / 日本語 / English / 한국어 / हिन्दी
- **玩法**：四条主题路线播放（镜头逐站飞行）、收藏、明信片拍照（季节相框）、
  御朱印收集、生成式和风/钢琴背景音乐与各景点环境音（WebAudio 实时合成，无音频文件）

## 技术

- Three.js（WebGL）单页应用，GSAP 镜头飞行，UnrealBloom 后期
- 纯静态部署于 Vercel；`index.html` 为主程序，`builders_src.js` 为景点建模模块
- `data/info.json` 为景点图文数据（部署时拆分上传，页面端合并）
- `deploy.py`：压缩 → 按 SHA 上传静态资源 → 创建 Vercel 部署

## 本地运行

任意静态服务器打开 `index.html` 即可（需要联网加载 Three.js CDN 与地图瓦片）：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```
